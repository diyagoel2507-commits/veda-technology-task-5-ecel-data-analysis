# VEDA Technology – Task 5 | Excel Data Analysis

> **Retail Sales Data Analysis using Microsoft Excel**

##  Project Overview

This project was developed as part of the **VEDA Technology Internship – Task 5**. The objective was to perform an end-to-end analysis of a structured retail sales dataset using Microsoft Excel.

The analysis focuses on transforming raw sales data into meaningful business insights through **Excel formulas, KPI calculations, PivotTables, sorting, filtering, and data visualization**.

---

##  Objectives

- Analyze structured retail sales data
- Calculate key sales and profitability metrics
- Apply Excel formulas for business analysis
- Create PivotTables to answer business questions
- Identify category, regional, and monthly sales patterns
- Build an interactive and professional Excel dashboard
- Generate actionable business insights

---

## Tools & Techniques

| Tool / Technique | Purpose |
|---|---|
| Microsoft Excel | Data analysis and visualization |
| Excel Tables | Structured data management |
| SUMIFS | Conditional sales analysis |
| COUNTIFS | Conditional order counting |
| AVERAGEIFS | Conditional average analysis |
| PivotTables | Business-level data analysis |
| Charts | Data visualization |
| KPI Cards | Performance monitoring |

---

##  Workbook Structure

The Excel workbook is organized into the following sections:

### 1. Raw_Data
Contains the original retail sales dataset and is kept separate to maintain data integrity.

### 2. Working_Formula
Contains calculated fields including:

- Sales
- Cost
- Profit
- Month

### 3. Summary
Contains the major KPIs and formula-based analysis.

### 4. Pivot_Analysis
Contains five PivotTables:

- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Profit by Category
- Quantity by Region

### 5. Dashboard
Provides a visual summary of the analysis using KPI cards and charts.

---

##  Key Performance Indicators

The dashboard tracks:

- **Total Sales**
- **Total Cost**
- **Total Profit**
- **Total Orders**
- **Total Quantity**
- **Average Order Value**
- **Profit Margin**

These KPIs provide a quick overview of overall business performance.

---

##  Business Analysis

The project answers important business questions such as:

- Which product category generates the highest sales?
- Which region contributes the most to sales?
- How do sales change month by month?
- Which category generates the highest profit?
- Which region has the highest quantity sold?

---

##  Key Findings

Sales and profit vary across categories, regions, and months. The analysis identifies high-performing segments and weaker areas, providing useful insights for improving sales, inventory planning, and business strategies.

---

##  Recommendations

- Focus on high-performing categories and regions.
- Improve promotional strategies for weaker segments.
- Monitor monthly sales patterns for better inventory planning.
- Analyze low-performing products to identify pricing or demand-related opportunities.

---

##  Dashboard

The final dashboard combines KPI cards, PivotTable-based analysis, and charts to provide a clear visual overview of retail sales performance.
